# Brühbuch

Rezepte, Gießplan und Ausrüstung für deinen Kaffee, als App für das Handy (PWA).

- Profil mit Ausrüstung: Brühgeräte, Mühlen, Waagen, Kocher und Filter, dazu Festlegungen wie Einheiten, Tassengröße, Verhältnis und Standardrezept.
- Stufen Anfänger:in, Interessiert und Profi.
- Gießplan mit ziehbaren Punkten, Brühhilfe, Bewertung mit Vorschlag und Tagebuch.

Die Daten bleiben auf dem Gerät. Gebaut wird die App im Projektordner `rezepte-app/` mit `bau.py`.
